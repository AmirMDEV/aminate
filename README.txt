Aminate release package

How to install or update:
1. Open Maya.
2. Drag 'Aminate_v0_3_5_drag_this_file_into_Maya.py' into the Maya viewport.
3. The tool updates installed files, refreshes the shelf button, opens Aminate, and docks it.
Use the versioned drag file above. Maya caches dropped Python files by filename, so the versioned name avoids older installer code being reused in the same Maya session.
Do not move the installer out of this folder. It needs the maya_anim_workflow_tools_package folder beside it.

If you already installed an older version, drag the new installer into Maya again.

Tutorials:
Open Aminate, go to Quick Start, and click Open Tutorials.
The local documentation is installed beside the Maya scripts at Aminate/docs/index.html.
The tracked feature wiki is installed beside the docs at Aminate/docs/wiki/README.md.
