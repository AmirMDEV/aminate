# Changelog

## Version 0.3.7 - 2026-08-01

- Animator's Pencil single-click drawing now creates only a near-zero-length dot at the cursor. Held drags keep the realtime sample and repaint path, so normal lines still draw continuously.
- Attaching a reference video now switches the active main Maya viewport to the same Pencil View camera while the floating or pinned Reference Viewer remains independent. The new normal-viewport action restores the previous camera without hiding the viewer.
- The Maya installer package is self-contained and can be dragged directly onto a Maya viewport. The offline tutorial site now ships as a separate `Aminate_v0.3.7_offline_tutorial.zip` release asset instead of being bundled into the installer ZIP.
- Re-dropping the versioned installer into a Maya session that already has Aminate installed is now safe: same-source runtime files and static folders are skipped instead of raising a self-copy error, so the shelf refresh completes cleanly.
- These new Pencil and reference-video workflows are in beta testing. The `0.3.7` release itself is not beta-labelled.
